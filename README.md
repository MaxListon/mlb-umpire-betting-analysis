# MLB Umpires and Their Influence on Sports Betting Lines

An INFO 201 group project exploring whether MLB home-plate umpire assignments are associated with opening totals, movement from opening to closing totals, home opening moneylines, and closing totals.

## Project materials

- [_Info final Pres.pptx](_Info%20final%20Pres.pptx): final presentation, including methods, visualizations, findings, and limitations.
- [info final pres code.pdf](info%20final%20pres%20code.pdf): accompanying code document supplied with the project.

## Data and approach

The presentation describes combining Sportsbook Reviews betting-line CSVs with Retrosheet game and umpire information. Preparation included standardizing dates and team abbreviations, reshaping betting records to one row per game, selecting relevant game variables, and removing approximately ten doubleheaders to simplify the merge.

## Findings and limitations

The visual analysis found no strong evidence of differences in betting lines associated with individual umpires. This is exploratory evidence, not a causal result or proof that umpires have no effect. The analysis covers one season and does not control for weather, starting pitchers, injuries, or team strength.
